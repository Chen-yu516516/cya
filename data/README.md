### PDF → Markdown 转换

使用 MinerU 将 PDF 转换为可检索的 Markdown 文本。转换产物位于 `week3/data/` 目录下，文件命名规则为 `{股票代码}_{公司简称}.md`。

### JSONL 数据提取

从 Markdown 中，通过正则表达式匹配"历史沿革"/"发行人设立以来的股本和股东变化"等章节，使用规则 + 信息提取管道生成 JSONL。数据文件位于 `week3/data/` 目录下：

```
{股票代码}_{公司简称}.jsonl          # 认缴流量 + 股权存量
{股票代码}_{公司简称}_full.jsonl     # 完整提取（含 extras）
{股票代码}_{公司简称}_transfers.jsonl # 股权转让
```

## 可复跑输入

运行 pipeline 需要以下输入：
1. `week3/data/` 下的 JSONL 文件 → 作为 week3_pipeline.py 的数据源
2. `week3/data/` 下的 Markdown 文件 → 作为 raw 阶段提取的文本源
