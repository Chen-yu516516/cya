# auto_output — 自动化产出

## 数据来源

- **7/8 家公司**：从招股书 Markdown 文件（PDF→Markdown 转换产物）起步，经章节定位、事件提取、Schema 校验输出 4-Sheet Excel
- **赛分科技（688758）**：招股书 Markdown 缺失，使用原始 JSONL 提取数据（原始提取源为 PDF）

## 处理管道文件

- `处理管道/markdown_to_excel.py` — 主处理脚本
  - 输入：招股书 Markdown（PDF 经由 MinerU 转换）
  - 输出：4-Sheet Excel（认缴流量 / 股权结构存量 / 交叉校验 / 股权转让）

## 已知局限

- **股权转让 Sheet**：当前处理管道不支持自动提取股权转让事件（JSONL 原始数据中缺少 `equity_transfer` 类型记录）。此 Sheet 在 auto_output 中为空，Gold 标准中已手动补全
