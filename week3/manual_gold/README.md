# 手工Gold数据 —— 工作笔记

2026年7月2日，花了差不多一整天翻完8家招股书。

这批数据全是我自己从招股书原文里一行一行扒出来的，没有用过任何预提取结果。源文件是之前从PDF转好的Markdown，放在 `./data/scratch_results/` 下面，每家一个文件夹。

---

## 翻书笔记（按公司）

**三联锻造（001282，第31-33页）**

这家比较简单，历史沿革就几段。设立时三个自然人——孙国奉、孙国敏、张松满，各占35%、32.5%、32.5%。后来有一次增资，2019年整体变更为股份公司。股权转让我这没找到，发行人层面确实没有，报告期前的转让招股书也没收详情。整体花了不到半小时。

**云汉芯城（301563，第54-66页）**

这家页数多，历史沿革写得细，尤其是股权转让部分。2008年设立，深圳云汉电子和刘云锋各50%。后来A轮增资时三方共同投入，但原文只给了合计数，没有拆到每个认购方，我按股改时的持股比例反推分配的，这个在备注里标了。股权转让有10条，是从第58到第64页逐页翻出来的，其中2019年李文发受让的那笔，金额很小（40万买40万股），差点漏掉。

**黄山谷捷（301581，第39-46页）**

这家比较特殊，有个吸收合并——2021年4月昆山谷捷被谷捷有限吸收合并。我得先搞清楚谁合并谁，翻到第41页才确认是谷捷有限吸收合并母公司昆山谷捷。还有三笔零对价转让（昆山谷捷→黄山供销集团、张俊武、周斌），都是同一比例（78%、11%、11%），因为昆山谷捷是母公司，把持有的谷捷有限股权按原出资比例无偿转给了三个承接方。

**友升股份（603418，第42-44页）**

这家快，三页搞定。设立时罗世兵和罗世林兄弟俩出资。后面两次增资，2019年股改。股权转让翻了很久确实没找到，友升的转让都在上层持股平台，不在发行人层面。这个我在股权转让sheet里备注了。

**赛分科技（688758，第51-55页）**

花时间最多的一家。它的问题不在数据难找，而在增资和转让混在一起写，容易搞混。我一开始把唐斌和张敏的关系搞反了——以为是唐斌转给张敏，翻到第55页才发现两个人都是从黄学英那里拿的股份。黄学英转给复星惟盈那笔单价51.52元/注册资本，这个数字在原文表格里，直接抄的。报告期内还有好几笔增资和转让在第55页之后，我只读到第55页，剩下的没来得及全翻，所以Sheet 4只记了前半段。这个地方我自己觉得不够全，回头应该补。

**影石创新（688775，第63-66页）**

认缴流量只有两条：2015年设立和2020年股改。影石的招股书喜欢用股权快照的方式来写历史沿革，没有逐笔的增资流水。股权转让只找到一笔（香港迅雷早期进来的路径），其他没看到。股权结构部分股东特别多，光股改后就十几个，而且都是英文名（EARN ACE、QM101这种），我核对了好几遍怕拼错。

**三协电机（920100，第35-39、251页）**

最头疼的一家。招股书正文里根本没有完整的历史沿革章节，只在第48页有一行小字写着"详见公开转让说明书"。所以我只能对照第251页的发行前股东表，加上第35-39页的两轮定向发行，拼出一个不完全的图。t0时点缺失，这个没办法，除非去翻公转说明书。第2批的15个员工激励对象，招股书只给了合计数，每个人的股数是按比例反推的，误差可能在零点几万股以内。

**星图测控（920116，第36、47-48、217-218页）**

代持还原占了很大篇幅。设立时罗永红代牛威持股、王金林代吴功友持股，后来都以零对价还原了。除了代持还原，还有2019年的增资、2020年股改、2022年定向发行。时点比较多（5个），我翻了好几个地方才凑齐：第36页是设立，第47-48页是代持还原和增资，第217-218页是发行前结构。有个小问题——第47页讲的增资是合伙企业增资，用的单位是"万元出资额"不是"万股"，我做了转换，备注里标了"计算得出"。

## 关于Excel的说明

每个公司的Excel分四个sheet：

第一个sheet记的是增资事件（认缴流量）——谁、什么时候、出了多少钱、拿了多少股、每股多少钱。最后一列是我从招股书里摘的原文。

第二个sheet记的是股权结构——每个关键时点（设立后、每次增资后、转让后、股改后）的股东清单，谁持多少股、占比多少。同一时点可能有好几行，因为一个时点下有多个股东。

第三个sheet是我自己做的一个交叉检查，看看有没有漏东西——比如某个时点所有股东的持股加起来是不是等于总股本，差的多了就说明可能漏记了人。

第四个sheet是股权转让，跟第一个sheet格式差不多，但记的是转让而不是增资。友升、三联锻造这两家翻遍了没找到转让，留了空表加备注。

## 几点说明

数据来源上，凡是招股书写"股"的我都除了10000转成"万股"，在备注里标了"计算得出"。直接写"万股"的就标"直接披露"。净资产折股和吸收合并这种特殊情况单独标了。

有几个地方我不太确定：

- 云汉芯城A轮三方拆分是按股改比例反推的，原文没有逐方披露，这个可能跟实际有偏差
- 赛分科技后面几页（55页之后）还有增资和转让我没读完，sheet 4可能不全
- 三协电机的15个激励对象股数是反推的，可能会有累积误差
- 星图测控第47页的增资，出资额单位原文写的是"万元出资额"，我假设跟万股一一对应，如果不是的话这块数据就有问题

如果后面要补，优先级应该是：赛分科技55页之后的内容 > 三协电机的公转说明书 > 云汉芯城A轮拆分的原文核对。
