## 二、赛分科技 Unit 修复详情

### 问题描述

Week 2 中赛分科技 (688758) 的 `subscription_shares_wan` 字段误填为原始股数（如 1,571,815.0），实际应为万股（157.1815）。其他7家公司的同一字段均正确使用万股单位，仅赛分科技存在此问题。

### 修复方式

- 修复脚本: `week3/data/fix_saifen_units.py`
- 修复日志: `week3/outputs/logs/saifen_unit_fix.log`
- 操作: 将所有 `record_type=subscription_flow` 记录的 `subscription_shares_wan` 除以 10000
- 修复范围: 共 10 条 subscription_flow 记录

### 受影响的记录

| 认购方 | 原始值(股) | 修正值(万股) |
|-------|-----------|-------------|
| 源峰磐赛 | 1,571,815.0 | 157.1815 |
| 珠海峦恒 | 628,726.0 | 62.8726 |
| 高瓴祈睿 | 628,726.0 | 62.8726 |
| 国药中生 | 461,846.0 | 46.1846 |
| 圣成投资 | 9,699.0 | 0.9699 |
| 国药二期 | 155,625.0 | 15.5625 |
| 圣祁投资 | 1,556.0 | 0.1556 |
| 夏尔巴二期 | 392,954.0 | 39.2954 |
| 甘李药业 | 235,772.0 | 23.5772 |
| 吴征涛 | 157,182.0 | 15.7182 |

### 证据

evidence_text 原文明确标注单位为"股"，如：
- "1 源峰磐赛 1,571,815" (认购股份，单位: 股)
- "合计 4,243,901" (股)

其他公司（如友升股份）的同一字段对应列标题为"认购数量（万股）"，单位本身即为万股，故无需除以 10000。

## 三、已知限制

### 3.1 影石创新 (688775)

- subscription_flow 记录为 0。招股说明书对增资过程的披露方式为按 time_point 的股权结构快照系列，未逐笔列出认购方与认购数量。
- 因此 `1_认缴流量` sheet 为空表。

### 3.2 星图测控 (920116)

- 股权结构仅覆盖 3 个时点（t0, t1, t2），时点覆盖较其他公司（如赛分科技覆盖十余个时点）少。
- 总记录数仅 19 条（6 subscription_flow + 13 equity_snapshot）。

### 3.3 黄山谷捷 (301581)

- subscription_flow 仅 3 条记录，但 equity_snapshot 有 21 条。部分增资事件已体现在股权快照的 column 对比中，但未做独立的 flow 记录。

### 3.4 云汉芯城 (301563)

- A轮第一/第二批（2014年、2015年）的三方共同增资中，PDF 未披露各认购方具体出资拆分。JSONL 当前按整体变更时持股比例反推分配（如 2:1:1），备注中已标注"PDF未披露各认购方具体出资拆分与认购金额"。

### 3.5 三协电机 (920100)

- 第1批（2022年）稳正景明/长泽创投的个别认购股数招股说明书未单独披露，按持股比例反向推算。
- 第2批（2023年）15名员工激励对象的个别股数通过"当前持股÷1.38"反向推算（2023年每10股转增3.80股权益分派还原）。

## 四、Gold Excel 结构说明

每家公司的 Excel 包含 3 个 Sheet:

### Sheet 1: `1_认缴流量`
- 筛选 `record_type=subscription_flow`
- 列: PDF页码 / 增资日期 / 批次标签 / 认购方 / 认购数量(万股) / 认购金额(万元) / 认购价格(元/股) / 原文证据
- 赛分科技所有数值均为已修正的万股

### Sheet 2: `2_股权结构存量`
- 筛选 `record_type=equity_snapshot`
- 列: PDF页码 / 时点 / 股权结构口径 / 总股本(万股) / 总出资额(万元) / 股东名称 / 持股数(万股) / 出资额(万元) / 持股比例 / 原文证据

### Sheet 3: `3_schema_cross_check`
- Schema 检查: 是否有认缴流量/股权存量记录、是否有 t0 时点
- Cross-check total: 按 time_point 加总股东持股 vs 总股本、股东出资 vs 总出资额
- Cross-check batch: 每批次认购方数量与合计认购数统计
- 校验结果列: pass / warn / fail
